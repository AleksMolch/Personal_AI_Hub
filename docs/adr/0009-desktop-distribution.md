# ADR-0009: Дистрибуция «как приложение» — PWA и Windows-инсталлятор

**Статус:** принято
**Дата:** 2026-10-19

## Контекст

Продукт self-hosted и работает в Docker Compose (Linux-контейнеры: web, api,
worker, beat, postgres, valkey, qdrant + опциональные профили). Пользователь
просил дать возможность «пользоваться платформой как приложением», в том числе
установочным файлом.

## Варианты

| Вариант | Описание | Стоимость | Решение |
| --- | --- | --- | --- |
| A. PWA | manifest + иконки + метаданные; «Установить как приложение» из Chrome/Edge | низкая | **делаем** |
| B. Windows-инсталлятор | PowerShell-скрипт (позже EXE): проверка Docker, `.env`, compose up, открыть браузер | средняя | **делаем (скрипт)** |
| C. Desktop-обёртка | Tauri/Electron + системный трей для старта/стопа + автообновление | средняя/высокая | отложить после B |
| D. Нативный bundle без Docker | embedded Postgres + встроенный vector/runtime, один бинарь | высокая, ре-архитектура | **отложить** |

## Решение

1. **PWA (A)** — минимальный путь к «окну-приложению» без изменения backend.
   Добавляются `manifest.json`, иконки (генерируются скриптом
   `infra/scripts/gen_icons.py`, бинарники не хранятся в Git) и метаданные в
   `app/layout.tsx`. Service worker/offline не добавляем: кэшировать Next-статика
   рискованно; офлайн-оболочка — отдельное решение, если появится потребность.
2. **Windows-инсталлятор (B)** — чистый PowerShell `install_windows.ps1` (без
   `make`/Git Bash, по `docs/WINDOWS_HANDOFF.md`): проверяет Docker, генерирует
   `.env`, поднимает стек, дожидается readiness, открывает `http://localhost:3000`.
   Идемпотентен. Самодостаточный `.exe` (Inno Setup/NSIS, архив без git) — как
   следующий шаг после ручной проверки скрипта.
3. **Нативный bundle (D)** — отдельное крупное решение: сейчас стек держится на
   Postgres/Valkey/Qdrant, замена их на embedded-аналоги меняет архитектуру.
   Возвращаться к нему — только с отдельным ADR и измерением ценности.

## Последствия

- Docker Desktop/Engine остаётся системным требованием; инсталлятор не бандлит
  Docker (лицензия и размер) и не обещает работу без сети.
- PWA — «окно» к `http://localhost:3000`; backend должен быть запущен.
- Иконки воспроизводимы: меняем `infra/scripts/gen_icons.py` и перегенерируем
  `apps/web/public/icons/*`, а не правкой PNG вручную.
