# ADR-0008: «Прямой доступ», предупреждения облака, окно контекста и хранение

**Статус:** принято
**Дата:** 2026-10-19
**Контекст:** после внедрения трёх режимов (ADR-0007) владелец попросил режим
полного доступа к API сторонних LLM для задач, не требующих защиты данных, и
упрощение работы без цен. Одновременно выяснилось, что история диалога уходила
провайдеру целиком, а старые данные никто не чистил.

## Решение

1. Добавить четвёртый режим `direct_cloud` — «Прямой доступ». В нём текст уходит
   провайдеру как есть: без сканирования, псевдонимизации, предупреждений и
   подготовки. Режим предназначен для задач без чувствительных данных.
2. Оставить режимом по умолчанию `cloud_controlled` («Облако с
   предупреждениями»), а не гибрид, как рекомендовал исходный гайд. Владелец
   продукта выбрал более простой старт; режим задаётся настройкой
   `DEFAULT_PROTECTION_MODE`.
3. Реализовать предупреждения облака: `POST /protection/scan` локально находит
   категории, UI показывает их в диалоге и даёт выбор «отправить как есть»,
   «перейти в гибрид» или «отмена». Это UX-слой, а не блокировка на уровне API:
   автоматизация не должна ломаться, а честность предупреждения обеспечивается
   интерфейсом и записью в снимке сообщения.
4. Считать цену необязательной на всех уровнях. Без цены запрос разрешён,
   стоимость пишется как `unknown`, бюджет не резервируется. UI объясняет
   последствия, но нигде не утверждает, что чат заблокирован.
5. Ограничить окно контекста: `CHAT_HISTORY_MAX_MESSAGES`,
   `CHAT_HISTORY_MAX_TOKENS` и лимит модели. Обрезка выполняется одним
   помощником и в `prepare`, и в отправке, иначе digest подготовки расходится с
   payload.
6. Добавить политику хранения: архив через 90 дней, удаление выключено по
   умолчанию, артефакты защиты — 30 дней, аудит — 90 дней. Задача
   `worker.retention` запускается раз в сутки.

## Последствия

- Четыре режима должны быть согласованы в enum, схемах, capabilities, UI, тестах
  и документации. Тест `capabilities` обновлён.
- «Прямой доступ» намеренно не выглядит защищённым: бейдж нейтрально-жёлтый, без
  зелёного акцента.
- Предупреждения облака не являются гарантией: прямой вызов API их минует. Это
  зафиксировано в документах по безопасности.
- Обрезка контекста означает, что модель может «забыть» ранние сообщения; UI
  показывает, сколько сообщений не передано.
- Архив не удаляет данные; удаление требует явной настройки и предупреждения в
  документации.
- Теги хранятся в `conversations.tags` (JSONB) и фильтруются на клиенте;
  серверная пагинация и фильтрация — следующий шаг.
