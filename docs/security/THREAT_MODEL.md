# Модель угроз защищённых режимов

Назначение: перечислить угрозы, которые режимы адресуют, и те, которые остаются.
Документ не является сертификацией и не обещает соответствия политикам.

## 1. Активы

- Приватные сообщения и документы пользователя.
- Карта псевдонимов (vault) и мастер-ключ.
- Ключи провайдеров.
- Деньги: бюджет и история расходов.

## 2. Что адресуется

| Угроза | Мера | Остаточный риск |
| --- | --- | --- |
| Утечка ПДн в облако | гибрид отправляет только sanitized-текст; проверка digest | детектор может пропустить сущность |
| Скрытая подмена режима | режим и ревизия в снимке; commit отклоняется при изменении | — |
| Повторное использование старого preview | digest + revision, идемпотентность | — |
| Чтение vault чужим пользователем | фильтр по user_id, 404 на чужое | компрометация БД + мастер-ключа |
| Восстановление значения в ссылку/картинку | запрет восстановления в URL/HTML | — |
| Возврат восстановленного текста в облако | история строится из sanitized-копий | ручное копирование пользователем |
| Prompt injection со страницы/документа | текст помечен как данные | модель всё ещё может подчиниться |
| Секреты в ответах модели | удаляются из входа; в vault не попадают | ключ мог быть уже отправлен в облачном режиме |

## 3. Что не адресуется

- **Анонимность**: модель видит структуру, суммы, стиль; псевдонимы
  восстанавливают смысл для локального пользователя.
- **Имена людей**: NER не реализован.
- **Компрометация хоста**: если злоумышленник уже на сервере приложения, он
  получает и БД, и мастер-ключ.
- **Инференция через локальный прокси**: локальный runtime ещё не реализован,
  поэтому `local_only` недоступен.
- **Egress-изоляция**: сетевые политики не настроены; в облачном режиме
  провайдер получает запрос по вашему выбору.
- **Модель без цены**: вызовы без цены пока запрещены (срез 6 в работе).

## 4. Границы доверия

- Браузер → API: HTTPS не обязателен для localhost, но для LAN нужен прокси.
- API ↔ PostgreSQL: локальная сеть Docker.
- API → провайдер: внешний TLS; содержимое — только sanitized-текст в гибриде.
- Vault: шифруется мастер-ключом; ключ не логируется и не возвращается API.

## 5. Проверки

- Интеграционные тесты перехватывают тело запроса к mock-провайдеру и
  подтверждают отсутствие приватных значений.
- Тесты на чужой пользовательский доступ и отказы по digest/revision.
- E2E проверяет, что preview показывает псевдонимы и отмена ничего не отправляет.

## 6. Обращение с инцидентом

1. Выключить `PROTECTION_MODES_ENABLED` и остановить api.
2. Ротировать мастер-ключ: сохранённые ключи провайдеров и vault станут
   нечитаемыми, это ожидаемо.
3. Проверить `usage_records` и логи на аномальные внешние вызовы.
4. Удалить затронутые подготовки и сообщения.
