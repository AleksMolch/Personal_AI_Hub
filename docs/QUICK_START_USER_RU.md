# Personal AI Hub — краткая инструкция пользователя

Назначение: провести нового пользователя от установки до первого ответа модели
без знания внутренней архитектуры. Подробности — в `README.md`; для Windows без
`make` см. `docs/WINDOWS_HANDOFF.md`.

## 1. Что нужно заранее

- Docker Desktop (Windows/macOS) или Docker Engine + Compose (Linux).
- 8–16 ГБ RAM, ~10 ГБ свободного места на диске (образы).
- Ключ API хотя бы одного провайдера (OpenRouter, RouterAI, Selectel или любой
  OpenAI-compatible сервис). Ключ вы вставляете в приложение; он хранится только
  у вас и шифруется.

## 2. Запуск

**Обычный способ (macOS/Linux или Git Bash):**
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd <ДИРЕКТОРИЯ>
make bootstrap   # создаёт .env со случайными секретами и собирает образы
make up          # поднимает стек
```

**Windows (без Git Bash):**
```powershell
powershell -ExecutionPolicy Bypass -File infra\scripts\install_windows.ps1
```
Скрипт сам проверит Docker, создаст `.env` (если его нет), соберёт и запустит
стек и откроет браузер.

Откройте **http://localhost:3000**.

## 3. Первый вход

На вкладке «Первый запуск» создайте администратора (логин и надёжный пароль).
Дальше вход — на вкладке «Вход».

## 4. Провайдер и модели

1. Откройте «Провайдеры» → «Добавить провайдера».
2. Выберите пресет (или вручную), вставьте Base URL и API-ключ.
3. Нажмите «Синхронизировать модели» — каталог моделей подтянется.
4. **Цена необязательна.** Без неё чат работает, но стоимость будет неизвестна
   и бюджет не сможет ограничить такие запросы. Цену можно задать позже на
   странице «Модели и цены».

## 5. Первый чат

1. Откройте «Чат» → «Новый диалог».
2. Выберите модель и при необходимости «Режим обработки данных»:
   - **Облако** — текст уходит провайдеру, перед отправкой показываем найденные
     данные;
   - **Прямой** — без проверок, для задач без чувствительных данных;
   - **Гибрид** — наружу уходит очищенный текст с псевдонимами;
   - **Локально** — только локальный провайдер (Ollama/LM Studio).
3. Напишите сообщение и отправьте (Enter — отправить, Shift+Enter — новая
   строка). Ответ идёт потоком, «Стоп» прерывает.

## 6. Расходы и бюджет (опционально)

На странице «Расходы» задайте дневной/месячный лимит. Пока лимит не превышен,
платные вызовы резервируются до отправки; при превышении — понятная ошибка.
Стоимость ответа видна прямо под сообщением (пометка «оценка» или «факт»).

## 7. Базы знаний и таблицы (кратко)

- **Базы знаний**: создайте базу (выберите embedding-модель), загрузите
  PDF/DOCX/TXT/MD или изображение, дождитесь задачи, задайте вопрос — ответ
  придёт с цитатами.
- **Таблицы**: загрузите CSV/XLSX, смотрите схему и задавайте SQL-запросы
  (только чтение).

## 8. Остановка и резервная копия

- Остановить: `make down` (или `docker compose down`).
- Бэкап: `make backup` (Linux/macOS, Git Bash); Windows — скрипт из
  `docs/WINDOWS_HANDOFF.md`.

## 9. Установить как приложение

В Chrome/Edge на `http://localhost:3000` нажмите «Установить» (иконка в адресной
строке или меню) — платформа откроется отдельным окном с собственной иконкой.
